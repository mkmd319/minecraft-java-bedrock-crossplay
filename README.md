## 先分清三种“互通”，买错基本都从这一步开始

### 基岩版内部跨平台

这是官方语境里的“跨平台联机”：安卓、iOS、Windows、Switch 之间互相进得去，因为大家本来就是同一个基岩版体系。网易 11 月 2 日的公告说的就是这件事，“iOS 玩家可与其他版本玩家正常联机，安卓端无需进行额外操作”，指的是基岩客户端之间，跟 Java 服没有关系。

### Java 与基岩的协议互通

Java 版基于 TCP 和 NBT 数据格式，基岩版依赖 UDP/RakNet，两套语言不通，中间必须加翻译层。通行的组合是三件套：Geyser 负责把基岩版数据包实时转成 Java 服务端认得的格式，Floodgate 完成基岩玩家与 Java 账号体系的映射，Velocity 做统一流量代理。

开两个端口不等于互通。账号体系、皮肤映射、物品 ID 差异、反作弊机制，任一环没接好，玩家进来就会觉得“能走但不对劲”。

### 网易版是另一套体系

网易版有独立的账号、登录方式、组件中心和服务器频道。网易版玩家一般连不到国际版互通服务器，除非服务器专门做了适配，或者玩家用支持第三方服务器的启动方式。这里涉及账号授权和用户协议，按官方规则走，别去研究怎么绕过验证。

| 名称 | 核心特征 | 典型平台 | 联机体系 | 互通难度 |
| --- | --- | --- | --- | --- |
| Java 版（JE） | 插件生态丰富、Mod 支持最强 | Windows、macOS、Linux | Java 协议 | 基准版本 |
| 基岩版（BE） | 跨平台能力强、移动端用户量大 | Android、iOS、Windows、Switch | 基岩协议 | 需要协议转换 |
| Beta 版 | 功能超前、稳定性不足 | 各平台测试版 | 协议不稳定 | 高，通常不与正式服互通 |
| 网易版 | 中国大陆代理、独立账号体系 | 网易客户端 PC / 移动 | 网易联机体系 | 高 |
| 网页版入口 | 免安装、浏览器直连 | 浏览器 | 与协议转换无关 | 不解决互通 |

网页版入口这类东西经常被误认成互通服。它解决的是客户端分发，让人不用装游戏就能进来看一眼，协议转换那层还是得服务器自己做。

## iOS 这一段单独说：10 月 30 日延迟，11 月 2 日已上线

时间线要按日期看，不然容易被旧消息带偏。

10 月 30 日，受苹果 App Store 审核流程超时影响，《我的世界》中国版 iOS 客户端没能按原计划完成版本更新，安卓端已正常更新。延迟期间 iOS 用户仍可正常登录，玩的是“铜器时代”版本内容，官方当时建议想体验新内容的玩家暂时改用安卓客户端或“基岩互通版”。注意官方这里用的“基岩互通版”仍然属于基岩体系，不是 Java 服。

11 月 2 日，iOS 客户端通过 App Store 审核并上线，iOS 玩家可与其他版本玩家正常联机，安卓端不需要做额外操作，现有版本保持互通。官方同时提醒更新前先备份本地存档，避免数据丢失。

所以现在的情况是：iOS 和安卓之间互通正常，这段延迟已经是历史。但它通的是基岩体系，你开的如果是 Java 服，iPhone 玩家照样进不来，除非服务端装了 Geyser。

## 互通之后，玩法也不是完全一样

红石电路、刷怪机制、农场效率、物品堆叠、攻击冷却，两个版本的细节都有差别。一个为 Java 版设计的生电服，基岩玩家进去后，很多自动化机器可能跑不出设计效率。这不是配置问题，是机制本身的差异。

开互通服之前想清楚主玩什么。纯生存、建筑、冒险地图，差异影响不大；红石生电、精密农场、竞技 PVP，就得提前定规则，比如哪些机器只允许 Java 玩家维护，或者干脆把两边的玩法区隔开。

## 临时开黑和长期开服，是两种东西

朋友临时开黑，人数少，房主电脑常开，虚拟局域网类工具完全够用，一分钱不用花。这类工具把不同宽带、不同运营商的设备拉进同一个虚拟局域网，Minecraft 还能自动发现成员开放的世界，省掉手输 IP。

## 服务器买回来，怎么不翻车

先分清三种“卡”，不然越查越乱：

1. 只有我卡，别人不卡 → 我的网络或我的电脑。
2. 所有人同一时刻一起卡 → 房主服务端。
3. ping 很低但操作有延迟感 → 不是网络，是 TPS。

第三句最容易踩坑。ping 只有 20ms 却一直在折腾路由器，实际是服务端上开了个刷怪塔把 TPS 压垮了。

四步定位，每步只改一个变量：

- ping 一下服务器 IP，看延迟和丢包。全部超时是链路没通，延迟高有丢包是链路质量差。
- 游戏里按 F3 看 fps 和内存占用。fps 低于 40 是本机性能问题，内存长期超 80% 会周期性卡顿。
- 测服务器上行带宽。上行 ≥30Mbps 时 3～5 人联机基本够用，只有个位数 Mbps 时人一多必卡。家庭宽带常见下行 300Mbps、上行只有 30Mbps，卡的是上行不是下行。
- 防火墙。Java 版要放行的是 `javaw.exe`，不是游戏启动器；360、电脑管家、火绒这类安全软件有独立拦截规则，排查时一并处理。

TPS 优化按收益排序：`server.properties` 里把 `view-distance` 从默认 10 降到 6、`simulation-distance` 降到 4，视觉上几乎看不出损失；清理掉落物、控制动物数量、给刷怪塔装开关；高频红石改低频；内存长期超 80% 就调大 `-Xmx` 并启用 G1，分配量别超过物理内存的 50%，超了会被系统杀进程，表现为玩着玩着闪退。

以上延迟、带宽、内存数值都是教程给出的经验参考，不同网络和机器差别很大，以本地实测为准。

如果这些都做完还是卡，答案通常是配置到顶了。整合包先在本地跑一晚看 TPS 和内存，撑不住就把服务端搬到云主机上，这一步绕不过去。
